# ctRSD-SeqCompiler
A Static Webpage for compiling ctRSD Circuit Components.

Based on https://github.com/usnistgov/ctRSD-simulator

## Docs
https://ctrsd-simulator.readthedocs.io/en/latest/

## Quickstart
1) Clone this repository
2) run `python -m http.server 8000 --directory app` in the root of this repo
3) Open webpage at http://localhost:8000
